# DBA Database Skills plugin

This skills-only plugin bundles five version-aware DBA skills for SQL Server 2022/2025, PostgreSQL 18, MySQL 9.7 LTS, and MariaDB 13.0. It includes no MCP server, database connection, or executable hooks.

Use the specific engine skill matching the target. The instructions are in Spanish and include progressive references, normalization through 3NF, version and edition checks, security, performance, recovery, and migration guidance. Read each skill’s `SKILL.md` and linked references as needed.

These materials support analysis and SQL drafting; they do not validate against your live database or authorize changes. Confirm business rules, patch/build, edition, storage engine, managed-service restrictions, and current vendor documentation before acting. Test recovery and operational changes in an environment matching production.

See the repository root `README.md` and `LICENSE` for installation, compatibility, contribution, limitations, and MIT terms.
