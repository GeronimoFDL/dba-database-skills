# Revisión de seguridad

- [ ] Usuarios de aplicación, despliegue, backup, monitoreo y administración separados.
- [ ] Permisos efectivos y pruebas negativas por identidad/tenant; mínimo privilegio.
- [ ] Autenticación y TLS verifican servidor/certificado; secretos fuera de repositorios y logs.
- [ ] SQL dinámico parametrizado; módulos privilegiados y resolución de nombres revisados.
- [ ] Cifrado, auditoría, retención y custodia de claves responden a requisitos concretos.
- [ ] Datos sensibles en planes, dumps y diagnósticos protegidos.
- [ ] Restauración de datos y recuperación de claves ensayadas.
- [ ] Dependencias de edición, plugins y servicio administrado comprobadas; sin certificación implícita.

Consulta [security](../references/security.md) y [backup-restore](../references/backup-restore.md).
